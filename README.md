# Noor Quran Academy – أكاديمية نور القرآن

App barnoota Qur'aanaa. Afaan Oromoo (jalqaba), Arabic fi English. Android irratti gaarii hojjata.

## Qur'aana Offline (quran-reader.html)

Fuulli kun Qur'aana Kareem guutuu (suurah 114, aayaata 6,236) **internet malee** dubbisuuf oolu.

**Amaloota:**
- Tarreeffama suurah 114 (maqaa Arabic'iin)
- Dubbisuu, qubee guddisuu/xiqqeessuu (A+ / A−)
- Barbaacha Arabic (kalima galchii, Enter tuqi)
- "Itti fufi": bakka dhaabbatte irraa itti fufuu
- Qur'aanni bilbila keessatti kuufama, internet hin barbaachisu

## Fayiliiwwan

## Akkaataa Itti Fayyadamuu

### Filannoo 1: User hundi al tokko buufata
1. `quran-reader.html` repo keessa kaa'i.
2. App banii **"Qur'aana buufadhu (internet al tokko)"** tuqi.
3. Booda internet gonkumaa hin barbaachisu.

### Filannoo 2: Qur'aanni app keessa duraan kuufame
1. [tanzil.net/download](https://tanzil.net/download) irraa buufadhu:
   - Quran Text Type: **Uthmani**
   - Output: **Text (with aya numbers)**
2. Maqaa fayilichaa **`quran-uthmani.txt`** godhi.
3. `quran-reader.html` waliin repo keessa kaa'i.
4. App'iin ofumaan dubbisa. Internet gonkumaa hin barbaachisu.

## Fayilii GitHub Irratti Upload Gochuu

1. Repo banii **Add file → Upload files** tuqi.
2. Fayiliiwwan fili, **Commit changes** tuqi.
3. **GitHub Actions** APK haaraa ijaara (Actions → Build APK).

## Madda Text Qur'aanaa

- Al-Quran Cloud API (`quran-uthmani` edition)
- [Tanzil.net](https://tanzil.net) (Uthmani)

Qur'aanni ofumaan hin barreeffamne. Madda sirrii irraa dubbifama. Maxxansuun duras yeroo muraasa Tanzil waliin wal bira qabii sirrii ta'uu isaa mirkaneessi.
